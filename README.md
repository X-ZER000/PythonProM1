# PythonProM1

Repositorio de aprendizaje estructurado de Python, desde nivel básico hasta avanzado.

Este repositorio documenta mi proceso real de aprendizaje, incluyendo:
- Código
- Ejercicios
- Proyectos
- Reflexiones técnicas
- Documentación por lección

## Estructura del repositorio

- `basics/`  
  Conceptos fundamentales de Python.

- `intermediate/`  
  Uso de librerías, bots, web y lógica intermedia.

- `advanced/`  
  Temas avanzados (IA, automatización, arquitectura).

- `exercises/`  
  Ejercicios prácticos y retos.

- `projects/`  
  Proyectos por módulo o nivel.

- `documentation/`  
  Notas por lección: qué entendí, qué no, y cómo aplicarlo.

## Objetivo

Construir una base sólida en Python y dejar evidencia clara de progreso técnico y pensamiento estructurado.

Este repositorio es parte de mi portafolio de aprendizaje.
