*** Objetivo del nivel intermedio ***

Pasar de “programar” a construir sistemas.
Aquí Python se conecta con web, datos y automatización real.

# Módulo 1 – Programación estructurada

*Lecciones=*
- Organización por archivos
- Importación de módulos
- Buenas prácticas

# Módulo 2 – Manejo de archivos y errores

*Lecciones=*
1- Lectura y escritura de archivos
2- try / except
3- Logs básicos

*Uso real=*
- Guardar datos
- Manejo de fallos
- Persistencia simple

# Módulo 3 – Desarrollo Web (nivel intermedio)

*Librerías=*
1- Flask
2- Requests

*Lecciones=*
1- Qué es un backend
2- APIs básicas
3- Rutas, métodos HTTP
4- Consumo de APIs externas

*Uso real=*
- Backends simples
- Bots conectados a servicios
- Webs dinámicas

# Módulo 4 – Web Scraping

*Librerías=*
1- BeautifulSoup
2- Scrapy

*Uso real=*
- Extraer información
- Automatizar investigación
- Recolección de datos

# Módulo 5 – Automatización

*Librerías=*
1- Selenium / Playwright
2- PyAutoGUI
3- smtplib

*Uso real=*
- Automatizar navegadores
- Envío de correos
- Bots funcionales
- Testing automático

# Módulo 6 – Datos estructurados

*Librerías=*
1- Pandas (intro)
2- Pydantic

*Uso real=*
- Validación de datos
- Análisis simple
